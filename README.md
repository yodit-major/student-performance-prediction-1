Student Performance & Academic Risk Prediction

A machine learning project that explores student academic performance and predicts final grades and potential academic risk.

Project Overview

This project uses student data to:

- Explore factors associated with academic performance.
- Predict students' final grades using regression models.
- Identify potential academic risk using classification models.

Team

This project is developed by a team of five members.

Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
